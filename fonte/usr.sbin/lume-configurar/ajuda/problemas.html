Ajuda do LumeBSD

Quando algo dá errado

Do mais simples ao mais forte. Nenhum destes passos apaga os seus arquivos.

1. Um programa travou

Feche a janela. Se ela não fechar, abra o Monitor do Sistema no menu, ache o programa e clique em Finalizar. Atalho: Ctrl+Esc.

2. Apaguei ou estraguei um arquivo

Botão direito no Dolphin, Versões anteriores. Veja a máquina do tempo.

3. O sistema ficou estranho depois de instalar algo

Remova o que instalou pelo app Programas do LumeBSD. Se não resolver, volte o sistema para uma foto de antes da instalação:

lume tempo linha       # as fotos, numeradas
lume tempo voltar 3    # como root: volta para a foto 3

4. Ficou estranho depois de uma atualização

Em Atualizações do LumeBSD, Voltar para a versão anterior, e reinicie.

5. A tela ficou preta ou travou ao iniciar

Desligue segurando o botão e ligue de novo. Se o driver de vídeo foi o culpado, o LumeBSD percebe e volta para o modo sem aceleração. Depois, lume hardware mostra o que aconteceu.

Se o problema começou numa atualização, ela também volta sozinha para a versão anterior no boot seguinte.

6. Nada disso resolveu

No menu de boot do LumeBSD (logo depois de ligar), a opção de ambientes de boot permite iniciar qualquer versão guardada do sistema. E para pedir ajuda, abra um relato em github.com/Kalel047/lumebsd/issues com a saída de:

lume
lume hardware
lume atualizar estado
